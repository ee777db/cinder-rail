Privacy

Cinder Rail is a public experimental compute service. No account, wallet connection, analytics tracker or advertising cookie is required.

The browser generates an agent signing key in memory. The private key remains in your browser and is lost on reload. The server stores your public key, temporary test-credit ledger, signed quotes, hashes, compute outputs and receipts for up to 24 hours. The private session token authorizes quotes and ledger reads. It stays in browser memory and is not included in exported receipts. Keep the token private.

For Llama inference, the text you submit is sent to Cloudflare Workers AI, running a Meta model. Do not submit secrets or sensitive personal information. Hash inputs are processed by the Worker and are not stored as plaintext in the session ledger. Outputs are retained temporarily so retries do not run paid compute again.

The service uses a daily salted hash of the connecting IP address to limit sandbox sessions. The application does not store raw IP addresses or enable request logging, although the hosting provider may process network data according to its own policies. Rate-limit records rotate daily.

The provider signs receipts with an operator-controlled key. Anyone who receives an exported receipt can read its fields. A signature proves the issuer and integrity, not that model execution was correct.

Test credits have no cash value, cannot be transferred and expire with the session. There is no purchase, deposit, withdrawal or token sale.
